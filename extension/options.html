LOCAL BROWSER CONTROL

Universal Agent Browser Bridge

Only tabs marked ON are visible to paired agents. Click the toolbar icon on a tab to share or revoke it.

Agent access

Skip click and Enter approval only in tabs created by the calling agent's label; hand-shared tabs still ask.

Enabled by default. Any local process with the bridge token can open agent tabs in your signed-in Chrome without a prompt. Turn off to ask before creating the agent window.

One domain per line. Each domain and its subdomains are blocked from agent access, including hand-shared tabs.

One absolute folder per line. Default: /Volumes/NVme/Projects/Stories/. An empty list disables file uploads. Relative paths, NUL characters and .. segments are ignored. Uploads require a tab owned by the calling agent and Chrome's “Allow access to file URLs” setting for this extension.

One absolute folder per line, separate from upload folders. Default: /Volumes/NVme/Projects/Stories/. An empty list disables downloads. Relative paths, NUL characters and .. segments are ignored. Downloads require a tab owned by the calling agent, use same-origin, trusted HTTPS, blob or data sources, and save up to 500 MB per file without Chrome's Save As prompt.

One hostname per line, for example *.googlevideo.com or flow-content.google. Empty by default. Allows cross-origin HTTPS downloads and redirects, with cookies kept inside Chrome. Exact entries match only that host; a leading *. matches subdomains at any depth, excluding the bare base. Matching ignores case and a trailing dot. Every redirect must use HTTPS and be same-origin or trusted; blocklisted hosts stay blocked. Snapshots and errors show hostnames only. Bare ASCII DNS names only, no schemes, paths, ports or IP literals. Only a single leading *. is allowed, with at least two labels after it. No public suffix list is checked (so *.co.uk is accepted). Invalid lines are ignored; saving shows the reasons.

Safety boundary

  • The bridge listens only on your computer.
  • Agents see only tabs you explicitly share or let them create.
  • Bank, card, payment and password-manager pages stay read-only, even in trusted tabs.
  • Creating the agent window asks for approval when automatic agent windows are turned off.
  • Remove a tab by clicking the toolbar icon again.
  • Do not share banking, password-manager, or payment tabs.
